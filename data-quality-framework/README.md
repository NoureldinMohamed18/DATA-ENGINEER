# 🛡️ Data Quality Framework & Automated Reporting Engine

إطار عمل (Framework) مرن وخفيف الوزن لفحص جودة البيانات (Data Quality & Validation) مبني باستخدام **Python** و **Pandas**. تم تصميمه للتعامل مع أي مجموعة بيانات (Generic) بصيغ مختلفة (CSV و Excel)، واكتشاف المشاكل الشائعة والشاذة، مع عزل السجلات المعيبة تلقائيًا وتوليد تقارير بصرية تفاعلية (HTML) وتقارير تقنية (JSON).

---

## 📌 مميزات المشروع (Key Features)

- **قواعد فحص مستقلة وشاملة (Modular & Generic Rules):** قواعد قابلة للتوسع والتطبيق على أي جدول بيانات دون الارتباط بأسماء أعمدة ثابتة.
- **عزل المشاكل دون حذف البيانات (Data Isolation Pattern):** فصل الصفوف المشكوك فيها في ملف منفصل (`flagged_records.csv`) مع توضيح سبب المشكلة لكل سجل، دون تعديل أو فقدان البيانات الأصلية.
- **تقارير بصرية احترافية (Client-Ready HTML Reports):** تحويل مخرجات الفحص إلى لوحة معلومات مرئية (HTML Dashboard) باللغة العربية مع نظام تصنيف للخطورة (Severity Levels).
- **أداة توليد بيانات تجريبية (Synthetic Dirty Data Generator):** سكريبت لحقن مشاكل جودة مقصودة لاختبار أداء النظام واستعراضه للعملاء.

---

## 🔍 قواعد الفحص المدمجة (Validation Rules)

النظام يفحص جودة البيانات عبر **8 قواعد متخصصة**:

1. **فحص القيم المفقودة (`check_missing_values`):** حساب عدد ونسبة القيم الفارغة (`Null/NaN`) في كل عمود مع تحديد الخطورة.
2. **فحص التكرارات (`check_duplicates`):** اكتشاف الصفوف المكررة بالكامل وحساب نسبتها.
3. **اكتشاف القيم الشاذة إحصائيًا (`check_outliers`):** استخدام طريقة المدى الربيعي (**IQR Method**) لرصد القيم الشاذة عن النمط الطبيعي.
4. **تناسق أنواع البيانات (`check_data_types`):** اكتشاف تضارب أنواع البيانات داخل نفس العمود (مثل خلط النصوص والأرقام).
5. **فحص القيم السالبة غير المنطقية (`check_negative_values`):** كشف القيم السالبة في أعمدة مثل (الرواتب، الأسعار، الأعمار، الكميات).
6. **التحقق من صيغة البريد الإلكتروني (`check_email_format`):** التأكد من مطابقة الإيميلات للصيغ القياسية عبر التعبيرات النمطية (`RegEx`).
7. **صحة التواريخ (`check_date_format`):** التأكد من إمكانية معالجة الأعمدة الزمنية واكتشاف التواريخ التالفة أو غير المنطقية.
8. **فحص المسافات الزائدة للنصوص (`check_string_whitespace`):** كشف المسافات الزائدة في البدايات والنهايات أو النصوص الفارغة لمنع مشاكل الـ `JOIN` والتجميع.
