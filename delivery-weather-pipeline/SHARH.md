# شرح سطر سطر — المشروع 3 (توصيل وطقس)

المجلد: `delivery-weather-pipeline`.

الفكرة من برّه: ملف شحنات + طقس كل مدينة من الإنترنت → شحنة عليها درجة حرارة ومطر وعلامة خطر تأخير.

---

## `src/config.py`

| السطر | المعنى |
|---|---|
| `from pathlib import Path` | نوع مسار ملفات |
| `import yaml` | قراءة ملف الإعدادات |
| `PROJECT_ROOT = Path(__file__).resolve().parents[1]` | من `src/config.py` اطلع مرتين تصل لفولدر المشروع |
| `path = PROJECT_ROOT / "config" / "settings.yaml"` | مكان الإعدادات |
| `yaml.safe_load` | نص الإعدادات → قاموس. لا ينفّذ كود |
| `resolve_path` | `data/raw` تصبح مساراً كاملاً |

---

## `src/extract/sources.py`

| السطر | المعنى |
|---|---|
| `extract_csv` يقرأ الملف كما هو | لا تنظيف هنا |
| `raise` لو الملف ناقص | توقف واضح |
| `for hub in hubs.itertuples` | لكل محور مدينة طلب طقس |
| `params latitude longitude current=...` | أوبن ميتيو يطلب الإحداثيات وحقول الطقس |
| `timeout` | لا انتظار بلا نهاية |
| `raise_for_status` | خطأ الشبكة يظهر فوراً |
| `current.get("precipitation") or 0.0` | لو مفيش مطر اعتبر صفر |

---

## `src/transform/clean.py`

| السطر | المعنى |
|---|---|
| `_reject` يكتب الصفوف السيئة | تراجع لاحقاً |
| `mode="a"` | إضافة وليس استبدال |
| `parse_dates` يبدأ بـ `NaT` | فارغ ثم نملأ الناجح |
| صيغة `%Y-%m-%d` أولاً | حتى لا يتكسر تاريخ مثل 2024-06-18 |
| `errors="coerce"` | النص الفاسد يصبح فارغاً لا خطأ يوقف الكل |
| وزن أقل من الحد أو أكبر → رفض | شحنة 90 كجم أو وزن سالب |
| `duplicated shipment_id keep last` | نحتفظ بآخر نسخة |
| `merge` الشحنة مع المحور ثم الطقس | نضيف المدينة ثم المطر |
| `delay_risk = مطر و express` | منطق العمل: السريع يتأثر بالمطر |

## `src/load/warehouse.py`

| السطر | المعنى |
|---|---|
| `PRAGMA foreign_keys = ON` | لا شحنة بمحور غير موجود |
| `date_key` رقم 20240601 | مفتاح تاريخ |
| `seed_dates` يوم بيوم بين أول وآخر شحنة | بعد التاريخ جاهز للتجميع |
| `ON CONFLICT DO UPDATE` للمحور | تحديث إحداثيات لو اتغيرت |
| `INSERT OR IGNORE` لنوع الخدمة | express مرة واحدة |
| العلامة المائية آخر تاريخ شحنة | التشغيل التالي للأجدد فقط |
| `INSERT OR IGNORE` للشحنة | نفس الرقم لا يتكرر |
| `pd.isna` قبل `float` | لا تحوّل الفراغ لرقم |
