# 🚀 End-to-End Data Engineering Pipelines

A comprehensive data engineering repository featuring two core pipelines: an API-to-SQL ETL pipeline and a Web Scraping to Document Store/Analytics workflow.

## 🛠️ Tech Stack & Skills
- **Languages:** Python (v3.13), SQL
- **Libraries:** Pandas, Requests, BeautifulSoup4, SQLite3
- **Data Modeling:** Star Schema (Fact and Dimension design)
- **Architecture:** ETL (Extract, Transform, Load) Pipeline

---

## 📌 Project 1: Automated API ETL Pipeline
- **Extract:** Ingests user data via REST API endpoints with built-in connection error handling and fallback logic.
- **Transform:** Cleans text fields, standardizes formats, and handles null values using `Pandas`.
- **Load & Modeling:** Implements a Star Schema in `SQLite` separating dimensions (`dim_users`) from transactional facts (`fact_orders`).
- **Analytics:** Computes customer lifetime metrics using multi-table SQL `JOIN`, `GROUP BY`, and aggregation functions (`SUM`, `COUNT`).

---

## 📌 Project 2: Web Scraping & Document Transformation
- **Extract:** Scrapes live product listings (titles, prices, availability) using `BeautifulSoup`.
- **Transform:** Normalizes raw price strings, extracts numeric features, and computes currency conversions.
- **Analytics / NoSQL Preparation:** Prepares structured JSON/BSON documents ready for NoSQL ingestion (MongoDB) or downstream analytical engines.
